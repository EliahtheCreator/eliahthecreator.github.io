# AI 视频与动态 3D 人才 Mapping Skill

## 适用场景

当你需要寻找 AI 视频、动态 3D/4D、世界模型、神经渲染、生成式 3D 或 AI-native runtime 方向的潜在候选人时使用本 Skill。

目标不是简单关键词搜索，而是判断一个人的公开研究经历是否真的支持目标岗位问题。

## 使用前确认

如果用户没有给出约束，先确认这些信息：

- 目标岗位或方向：`{目标方向}`
- 地域范围：不限 / 中国 / 北美 / 欧洲 / 其他
- 学术阶段：PhD / Postdoc / Industry Researcher / 不限
- 论文要求：是否要求顶会、是否要求一作或共一
- 是否需要联系方式
- 输出形式：候选人表格 / 候选人排序 / 外联话术 / Excel 表

## 核心判断

不要只按关键词找人。先把岗位翻译成底层技术问题，再判断候选人是否有真实连接。

常见研究线包括：

- AI 视频生成：可控视频生成、视频编辑、视频评估、模型组合、效率优化、长时序一致性。
- 动态 3D/4D：动态场景、4D 表征、video-to-3D/4D、dynamic Gaussian Splatting、deformable scenes。
- 神经渲染与生成式 3D：NeRF、3DGS、generative 3D、avatar、digital human、scene generation。
- AI-native runtime：交互、编辑、资产化、仿真、空间智能、生成内容运行底座。

候选人不一定要使用“AI video x dynamic 3D”这些词。动态神经场、4DGS、视频扩散、世界模型、生成式 3D 系统方向的人也可能高度相关。

## 信息渠道

优先使用公开、可核验的来源：

- Google Scholar
- Semantic Scholar
- DBLP
- OpenReview
- arXiv
- Papers with Code
- 个人主页
- 实验室主页
- GitHub
- 项目主页
- 论文 PDF
- 官方机构页面

不要把二手报道当作身份、阶段或贡献的唯一证据。

## 筛选维度

### 技术相关性

- 是否真正连接视频、动态 3D/4D、世界模型、生成式 3D 或神经渲染。
- 是否只是静态重建，还是能连接动态内容、生成、编辑或交互。
- 是否有系统、代码、Demo、项目页、数据集或 benchmark。

### 贡献深度

- 是否是一作、共一或核心贡献者。
- 是否有持续研究主线，而不是零散参与。
- 是否能看出方法、系统、评估或数据方面的实际贡献。

### Owner Signal

Owner Signal 用来判断候选人是否可能定义问题、组织方向和推进复杂项目。

分三档：

- 强：有连续研究主线，能提出任务、系统、数据集、benchmark 或方法框架。
- 中：研究能力强，有一定方向形成迹象，但公开材料里独立 ownership 不够明确。
- 弱：技术质量不错，但更像模块执行、支持、优化或单点参与。

Owner Signal 弱不代表候选人不好，只代表更适合 specialist 或 collaborator 角色。

## 常见误判

避免这些 false positive：

- 只有 AIGC、video、3D 关键词，没有算法或研究 ownership。
- 只有应用 Demo 或 API 调用。
- 只有静态重建，与生成或动态内容关系弱。
- 论文多但个人贡献不清晰。
- 项目看起来很贴，但候选人只负责边缘模块。

## 联系方式收集规则

只收集公开职业联系方式：

- 个人主页邮箱
- 学校或实验室邮箱
- GitHub 公开邮箱
- 项目页或论文公开邮箱
- 公开主页里的社交账号

不要推断私人手机号，不要抓取私密社交账号。猜测邮箱格式时必须标注“未验证猜测”。

## 去重规则

跨批次 Mapping 时，用轻量去重：

1. 邮箱完全一致：视为同一人。
2. 主页或 Google Scholar 链接一致：视为同一人。
3. 姓名 + 学校/机构一致：标记为疑似重复，人工确认。

不要为了去重反复重查每个人全部论文。

## 外联话术原则

外联时不要一上来像硬招聘。更适合表达成方向交流：

```text
我最近在关注 AI 视频、动态 3D 和可交互生成内容这个交叉方向，看到你在 {研究方向} 上的工作很有意思，尤其是 {具体作品/项目}。

如果你方便的话，想和你交流一下这个方向未来如何从生成走向可编辑、可运行、可使用的动态内容系统。
```

## 完成时必须说明

每轮 Mapping 结束后说明：

- 使用了哪些约束。
- 检查了哪些来源。
- 哪些字段还需要二次确认。
- 联系方式是否为公开可验证联系方式。
- 是否有范围 caveat，例如是否包含港澳台、海外华人或非目标地区候选人。

## 安全边界

- 不公开历史候选人库。
- 不公开内部优先级、内部表格或内部外联记录。
- 不公开非公开联系方式。
- 不把候选人名单作为网页公开素材。
